# SO-101 运动学实验

## 学习内容

- DH 参数与齐次变换
- 正运动学（FK）
- 逆运动学（IK）
- 位置雅可比矩阵
- 阻尼最小二乘（DLS）伪逆

## 实验结果

从零初始关节角开始进行 IK 迭代：

- 迭代次数：9 次
- 末端位置误差：约 0.6165 mm
- 在 MuJoCo 中进行了独立的末端位置交叉验证

该结果用于验证本次目标点的运动学求解，暂不代表真实机械臂的实际控制精度。

## 当前理解

雅可比矩阵把关节空间的小变化映射到末端位置变化。接近奇异姿态时，使用阻尼伪逆可以减小数值不稳定问题。

## 后续

继续验证多个目标点，绘制误差曲线，并将运动学结果用于末端轨迹控制。
