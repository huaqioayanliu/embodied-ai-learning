# SO-101 开源代码研究记录

## 研究对象

当前阅读的开源项目是 `so101-classical-robotics`，重点关注：

- `robot_params.py)：机器人关节、连杆和几何参数
- `kinematics/fk.py)：正运动学和齐次变换
- `kinematics/ik.py`：逆运动学和阻尼最小二乘
- `controllers/`：位置控制、力矩控制和反馈控制
- MuJoCo 模型与仿真测试代码

## 我的阅读重点

### 1. 正运动学

通过连续的齐次变换计算各连杆和末端执行器的位置。代码中需要特别注意：

- 关节角的单位和零位定义
- 坐标系之间的变换顺序
- 末端偏移量 `EE_OFFSET`
- MuJoCo 模型坐标系与 Python 参数的对应关系

### 2. 逆运动学

项目使用雅可比矩阵和阻尼伪逆逐步修正关节角。每次迭代根据末端位置误差计算关节角增量，接近奇异姿态时通过阻尼项提高数值稳定性。

### 3. 控制器

当前重点阅读位置控制和力矩 PD 控制，理解目标角度、当前角度、角速度、误差和控制力矩之间的关系。

## 当前验证结果

- IK 从零初始角开始，9 次迭代收敛。
- 末端位置误差约为 0.6165 mm。
- MuJoCo 中进行了独立的末端位置交叉验证。
- SO-101 的力矩 PD 实验显示，干摩擦会造成明显的稳态位置误差。
