# SO-101 控制实验记录

## 1. 位置控制

使用 MuJoCo 的位置执行器设置关节目标位置，观察单个关节运动。该实验用于理解：

- 目标位置如何传给执行器
- `data.ctrl` 的含义
- `mj_step()` 如何推进仿真
- 关节位置和执行器输入的关系

## 2. 力矩 PD 控制

对 `shoulder_lift` 关节进行力矩控制：

```text
tau = Kp * (q_target - q) - Kd * qdot
```

实验目标为从 -30° 运动到 -25°。

## 3. 摩擦影响

- 保留原始干摩擦时，最终约停在 -26.14°。
- 临时设置 `frictionloss=0` 后，约 2.5–3 秒到达 -25°。

这说明控制误差与模型中的干摩擦、阻尼、重力和惯性参数有关。取消摩擦只是对照实验，不能直接作为最终控制方案。
