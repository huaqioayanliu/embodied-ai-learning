# SO-101 力矩 PD 与摩擦影响实验

## 实验目标

控制 `shoulder_lift` 关节从 -30° 运动到 -25°，观察力矩 PD 控制和干摩擦对最终姿态的影响。

## 对照结果

| 条件 | 结果 |
|---|---|
| 保留原始干摩擦 | 约停在 -26.14°，存在稳态偏差 |
| 临时设置 `frictionloss=0` | 约 2.5–3 秒到达 -25° |

## 实验认识

PD 控制的结果不仅取决于比例和微分增益，还受到模型中的干摩擦、阻尼、重力和惯性参数影响。临时取消干摩擦用于定位问题，后续需要在保留合理物理参数的情况下继续学习重力补偿和动力学控制。

## 相关模型

实验使用 MuJoCo 中的 SO-101 torque scene。具体实验代码和终端输出截图将继续补充。
