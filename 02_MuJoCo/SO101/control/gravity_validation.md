# SO-101 重力项验证

## 验证目的

对比 Python 中根据机器人动力学递推得到的重力力矩，与 MuJoCo 在相同姿态下计算得到的重力项，检查模型参数、关节顺序和坐标系是否对应。

## 验证内容

- 使用 SO-101 当前姿态进行计算。
- 根据连杆质量、质心、惯性和关节坐标进行动力学递推。
- 读取 MuJoCo 中对应关节的重力相关力矩。
- 对比两种方法得到的重力项方向和数量级。
- 对活动夹爪影响进行处理后再次核对。

## 学习到的内容

重力补偿的核心是估计当前姿态下各关节需要抵消的重力力矩。这个力矩随机械臂姿态变化，不是一个固定常数。

验证时需要重点检查：

1. Python 关节顺序与 MuJoCo 的关节索引是否一致。
2. 模型中的质量、质心和惯性参数是否对应。
3. 坐标系方向和旋转矩阵是否一致。
4. 是否把执行器、摩擦和夹爪等额外因素混入比较。

## 当前结论

已完成当前姿态下的重力项对照，并继续核对递推代码与 MuJoCo 数据结构。该验证用于检查动力学建模的一致性，不等同于完整的真实机械臂重力补偿实验。
