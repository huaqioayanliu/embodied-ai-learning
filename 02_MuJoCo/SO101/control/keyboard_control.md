# SO-101 键盘控制研究

## 研究目标

阅读开源项目中的键盘控制代码，理解键盘输入如何转换为关节目标、速度目标或控制器输入。

## 重点阅读内容

- 键盘按键与关节名称的映射
- 单步增量和连续控制的区别
- 目标关节角 `q_target` 的更新方式
- 控制循环、仿真步进和按键事件处理
- 关节限位与安全停止
- 键盘控制与 MuJoCo Viewer 的关系

## 与位置控制、力矩控制的关系

键盘本身只提供离散输入，例如“某个关节增加一点角度”。真正让关节运动的仍然是后面的控制器：

```text
键盘输入
    -> 更新目标关节角
    -> 位置控制或 PD 控制
    -> MuJoCo 执行器
    -> mj_step()
```
